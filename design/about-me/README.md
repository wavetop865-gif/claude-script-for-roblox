# Дизайн личного сайта «Обо мне»

Готовый макет одностраничного сайта-портфолио для Malo Paul.

## Структура страницы

1. **Hero** — имя, роль, краткое описание, CTA-кнопки, статистика
2. **Обо мне** — текст о себе + карточки (фокус, подход, ценности)
3. **История** — таймлайн 2022–2025
4. **Навыки** — разработка, дизайн, инструменты
5. **Проекты** — карточки работ
6. **Контакты** — email и GitHub

## Как посмотреть

Откройте `index.html` в браузере или запустите локальный сервер:

```bash
cd design/about-me && python3 -m http.server 8080
```

Затем откройте http://localhost:8080

## Перенос в Figma

Этот HTML-макет можно использовать как референс при создании макета в Figma:

- **Цвета:** фон `#0A0A0C`, карточки `#18181C`, акцент `#C8B6FF` → `#7EE8FA`
- **Шрифты:** Playfair Display (заголовки), Manrope (текст)
- **Ширина фрейма:** 1440px (Desktop), 390px (Mobile)

## Настройка контента

Замените placeholder-текст в `index.html` на свою реальную историю, фото и проекты.
