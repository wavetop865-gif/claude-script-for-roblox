# lingo

переводчик под роблокс экзекютор. просто кидаешь в execute и всё.

язык интерфейса можно сменить в шапке (ru / en / ua). перевод сам определяет язык, или выбираешь руками. окно тянется за края, таскается за верх.

в настройках (⚙) можно выбрать тему, цвет UI (пикер сам собирает тёмные/светлые оттенки), раскладку интерфейса, как окно ездит и анимацию открытия.

## запуск

1. открой экзекютор (нужен http: request / syn.request)
2. вставь `script.lua`
3. execute

RightShift — спрятать/показать, Enter — перевести.

если перевод не идёт — скорее всего экзекютор режет http.
