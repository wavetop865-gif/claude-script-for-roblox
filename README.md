# Lingo — переводчик для Roblox-экзекютора

Красивый UI-переводчик с сменой языка интерфейса и десятками языков перевода.

## Возможности

- **Язык UI:** RU / EN / UA (кнопки в шапке)
- **Перевод:** авто-определение + 20 языков (EN, RU, UA, DE, FR, ES, …)
- **Swap** языков и текста
- **Copy** результата в буфер
- **История** последних переводов
- Анимации, ambient-орбы, тёмная teal-тема
- Перетаскивание окна за шапку

## Управление

| Клавиша | Действие |
|---------|----------|
| `RightShift` | Показать / скрыть меню |
| `Enter` | Перевести (когда фокус в поле ввода) |
| `Esc` | Закрыть выпадающий список / скрыть окно |

## Как запустить

1. Открой любой Roblox-экзекютор с HTTP (`request` / `syn.request` / `http_request`).
2. Вставь содержимое [`script.lua`](script.lua).
3. Нажми **Execute**.

Перевод идёт через публичный Google Translate endpoint. Нужен рабочий HTTP в экзекюторе.

## Файлы

- `script.lua` — весь скрипт (UI + логика + i18n)
