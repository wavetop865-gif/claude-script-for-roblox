# Pulse Optimizer

Минималистичное Android-приложение для оптимизации телефона: тёмный графитовый интерфейс с мятным акцентом, анимированный круговой индикатор «здоровья» устройства и живые метрики системы.

<p align="center"><i>Kotlin · Jetpack Compose · Material 3</i></p>

## Возможности

- **Индекс здоровья** — сводная оценка состояния устройства (0–100) на основе загрузки оперативной памяти, заполненности накопителя и заряда батареи, отображается на анимированном круговом индикаторе с «дышащим» ореолом.
- **Живые метрики** — четыре карточки: оперативная память, хранилище, батарея (с индикацией зарядки) и объём кэша, который можно освободить.
- **Оптимизация в одно касание** — анимированный процесс сканирования и очистки: приложение реально очищает собственный кэш (единственный кэш, доступный обычному приложению на современных версиях Android) и обновляет метрики.
- **Результат** — всплывающая нижняя панель с объёмом освобождённого места и новым индексом здоровья.

## Дизайн

Единый тёмный стиль: графитовый фон `#0B0E14`, мятный акцент `#4FE3C1`, тонкие линии прогресса, скруглённые карточки, плавные анимации (появление шкалы, орбитальная точка вокруг индикатора, слайд нижней панели). Никаких лишних экранов — всё на одном.

## Сборка

Требуется JDK 17+ и Android SDK (platform 35).

```bash
# укажите путь к SDK
echo "sdk.dir=/path/to/android-sdk" > local.properties

./gradlew assembleRelease
```

Готовый APK: `app/build/outputs/apk/release/app-release.apk`.

Собранный APK также лежит в [`dist/pulse-optimizer-1.0.0.apk`](dist/pulse-optimizer-1.0.0.apk) — его можно сразу установить на телефон (release-сборка подписана debug-ключом, поэтому ставится без Play Market; включите «установку из неизвестных источников»).

## Структура проекта

```
app/src/main/java/com/pulse/optimizer/
├── MainActivity.kt            — точка входа, edge-to-edge
├── OptimizerViewModel.kt      — состояние экрана, процесс оптимизации
├── data/DeviceStats.kt        — чтение метрик системы, очистка кэша
└── ui/
    ├── MainScreen.kt          — главный экран и панель результата
    ├── components/
    │   ├── HealthGauge.kt     — круговой индикатор здоровья (Canvas)
    │   └── StatCard.kt        — карточка метрики
    └── theme/                 — палитра и типографика
```
