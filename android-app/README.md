# Сфера

Минималистичное Android-приложение для честной диагностики устройства.

## Возможности

- показывает реальную загрузку внутреннего хранилища и оперативной памяти;
- отображает заряд, статус зарядки и температуру аккумулятора;
- безопасно удаляет только собственные временные файлы;
- открывает системные экраны управления памятью и энергосбережением;
- не требует опасных разрешений и не завершает чужие приложения.

Android не разрешает обычному приложению очищать данные других программ или
принудительно «ускорять» систему. Сфера не имитирует такие действия и передаёт
пользователю контроль через штатные настройки Android.

## Сборка

Требуются JDK 17+ и Android SDK 34:

```bash
./gradlew assembleDebug
```

APK будет создан в `app/build/outputs/apk/debug/app-debug.apk`.
