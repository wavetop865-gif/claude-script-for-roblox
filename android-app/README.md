# awp.gg Menu Demo (Android)

Демо-приложение с интерфейсом меню в стиле **awp.gg** из `script.lua`.

## Что это

- Тёмное монохромное меню с вкладками: Visuals, Combat, Movement, Misc, Settings
- Тогглы, слайдеры, кнопки и keybind-поля — **работают в UI**
- Анимированный фон со «звёздами»
- Перетаскивание меню за заголовок
- Долгое нажатие на тоггл открывает поднастройки (как в оригинале)

## Что НЕ работает

Это **только демо интерфейса**. Никаких игровых функций (ESP, Aimbot, Fly и т.д.) нет и быть не может — приложение не связано с Roblox.

## Установка APK

1. Скачайте `awp-menu-demo.apk` из корня репозитория (или соберите сами).
2. На Android включите «Установка из неизвестных источников».
3. Установите APK.
4. При первом запуске разрешите **«Поверх других приложений»** — меню будет плавать поверх любых приложений.
5. Нажмите «Запустить меню» и перейдите в другое приложение — меню останется сверху.

## Управление

| Действие | Как |
|---|---|
| Запуск поверх экрана | Первый запуск → разрешение overlay → «Запустить меню» |
| Переключить вкладку | Нажать на название вкладки |
| Вкл/выкл опцию | Нажать на тоггл |
| Поднастройки | Долгое нажатие на тоггл |
| Переместить меню | Тянуть за заголовок «awp.gg» |
| Скрыть меню | Кнопка «—» (звёзды исчезают, остаётся только чип) |
| Показать снова | Нажать «awp.gg \| tap to open» |
| Полностью закрыть | Кнопка «×» или уведомление → «Закрыть» |
| Watermark | Settings → HUD → Watermark (FPS) |

Звёзды отображаются **только внутри открытого меню** — при скрытии или закрытии они пропадают.
