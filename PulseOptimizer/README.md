# Pulse Optimizer

Минималистичное Android-приложение для оптимизации телефона + бесплатный VPN.

## Готовый APK

[`apk/PulseOptimizer-debug.apk`](apk/PulseOptimizer-debug.apk)

## Возможности

### Оптимизация
- **Индекс здоровья** — неоновое кольцо 0–100 (RAM + хранилище + батарея)
- **Быстрое ускорение** — очистка кэша и освобождение памяти
- **Глубокая очистка** — временные файлы, логи, code-cache, `.tmp`
- **Забота о батарее** — анализ температуры и советы по энергосбережению

### VPN (отдельный раздел)
- Живой список **бесплатных серверов [VPN Gate](https://www.vpngate.net/)** (Университет Цукубы, Япония)
- Сортировка по качеству, ping, скорость, страна
- Подключение через OpenVPN-конфиг (открывается в OpenVPN Connect)
- Альтернатива: L2TP/IPsec — логин `vpn`, пароль `vpn`, ключ `vpn`

## Технологии

- Kotlin 2.0, Jetpack Compose, Material 3
- minSdk 26, targetSdk 34
- Без платных VPN-сервисов — только публичные серверы VPN Gate

## Сборка

```bash
cd PulseOptimizer
./gradlew assembleDebug
```
