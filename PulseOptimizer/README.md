# Pulse Optimizer

Минималистичное Android-приложение для оптимизации телефона с уникальным неоновым интерфейсом в стиле «глубокий космос».

## Готовый APK

Собранный APK лежит в этом репозитории: [`apk/PulseOptimizer-debug.apk`](apk/PulseOptimizer-debug.apk).
Скачайте его на телефон, разрешите установку из неизвестных источников и установите.

## Возможности

- **Индекс здоровья устройства** — анимированное неоновое кольцо с общей оценкой 0–100, рассчитанной из свободной оперативной памяти, свободного хранилища и заряда батареи.
- **Живой мониторинг** — реальные данные каждые 4 секунды:
  - оперативная память (занято / всего);
  - хранилище (занято / всего);
  - батарея (заряд, температура, статус зарядки).
- **Кнопка «Ускорить»** — анимация сканирования, очистка кэша приложения и обновление индекса.
- **Уникальный дизайн** — тёмная палитра «Deep Space», плавающие цветные «авроры» на фоне, градиентные кольца и карточки, всё на Jetpack Compose и Material 3.

## Технологии

- Kotlin 2.0, Jetpack Compose (Material 3)
- minSdk 26 (Android 8.0+), targetSdk 34
- Без сторонних зависимостей и без лишних разрешений

## Сборка из исходников

Требуется JDK 17+ и Android SDK (platform 34):

```bash
cd PulseOptimizer
./gradlew assembleDebug
```

APK появится в `app/build/outputs/apk/debug/app-debug.apk`.
